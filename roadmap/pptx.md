# pptx 编辑路线

只记账顺序，不验收。PowerPoint 全量指包里能表达的对象都能进 inspect、能 apply、create 能按同一套 JSON 生成。不是复刻 PowerPoint 运行时。

docx 见 [`roadmap/docx.md`](docx.md)。xlsx 见 [`roadmap/xlsx.md`](xlsx.md)。`ooxp mcp` 是命令行入口，不在本目录开切片。领域 JSON 原样交给库。

pptx 模块不要引用 `docx::` 或 `xlsx::`。`c:chart`（§21.2）用 `crates/ooxp/src/chart/`。每份计划仍是：先改当期 `docs/`，确认后再动代码。挂机一次只开一份，从待做序号 0 起。当期切片写在 `.plan/`，不写进本目录。

## 永不做 🚫

- 排版引擎、按新画布重排。只读 PNG 见待做 59。金样见已过 C23，不把像素写回包
- 放映引擎、任意时间轴树仍永不做（预设效果写入见已过 12）。幻灯片 PNG 不是放映
- 做一套 VML 绘图引擎。未点名的 VML / `p:legacyDrawing` 原样写回。PowerPoint 16.0 若不再把对象写在这里，C22 对本格式标 🚫
- 默认把图片字节或 embedding 塞进 inspect 树
- 把 `p:pic` 当成 `slide:…/shape:…`（形状只收带 `p:txBody` 的 `p:sp`，已验收契约不拆）
- SmartArt 版式算法
- 执行宏、打印本身
- `.ppt`

旧式 `commentAuthors`（ECMA-376 §19.4）继续忽略。`vbaProject.bin` 未点名则原样写回。

## 不单开

- 组合 `p:grpSp` 里的图、图表、SmartArt：展开符合条件的子节点，组合本身不进树
- 备注页、批注里的图：跟容器走，复用图片 op
- `exportMedia`：跟幻灯片图走；pptx OLE 共用同一动作，写出 embeddings
- `exportChartData`：跟幻灯片图表走
- 复制已有文件再 apply：不必新动作
- 功能区艺术字：另存是带 `p:txBody` 的 `p:sp`，已进形状树。不新开对象。字填充 / 轮廓见已过 C10
- `/ppt/tableStyles.xml` 里的样式定义本体：52 只写表上的 GUID 与 `tblPr` 开关。不够用时补进 `.plan/2026年-9月-27日-✅-pptx-表格.md`
